Welcome to Path Heroes!

This is a mouse-only game. 
The character moves autonomously along an already prepared path when the start button is pressed.
Once you press start you cannot move the character but you can interact with its surroundings - click tiles to change the path the character is travelling on to get the character to the marked end point. 
Complete the puzzle within the time limit without getting hit by any obstacles in order to progress to the next level.
Make sure to time these changes you make to the track - you may lead your character to their doom...
Good Luck!
