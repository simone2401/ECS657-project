Player's Manual：
1. Use the mouse to choose the character's starting point
2. Once you press start you cannot move the character but you can interact with its surroundings 
3. click switches to change where the character is going and hold down on pressure plates to change the environment

Game:
1. Characters move autonomously along rails that are already laid out, move at same timewhen level starts
2. Buttons to start and restart level
3. Different characters with their own abilities they activate automatically
4. Start and end points for each character, player can choose where to start each characterbut end points are set and can't be changeda. Player drags character to start point
5. Display time limit for each level to be completed within that counts down how much timeis left when level starts
6. Level menu where player can choose level
7. 3D world where player can see entire level at once, level uses grid system to lay out objects
8. Ability to interact with objects
  a. switches to change where the character is goingb.
  b. pressure plates that when held down, change the environment
9.Characters have health and die when they collide with each other
10. Win and fail screen
